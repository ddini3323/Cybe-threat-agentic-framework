================================================================================
CHAPTER 9 - CONCLUSION
================================================================================

This project successfully designed, implemented, and evaluated a
Context-Aware Cyber Threat Analytics and Mitigation Recommendation system
using Large Language Models. The system addresses a real operational gap in
Security Operations Centres [24][2] — the manual bottleneck in threat
enrichment, classification, and response — through a fully local,
privacy-preserving, five-agent pipeline served via a SOC-style web dashboard.

All four stated objectives were achieved:

  Objective 1 (Context-Aware Enrichment):
    The RAG-augmented enrichment agent [25][14] extracts IOCs, TTPs, CVEs,
    attack vectors, and affected assets with 84.7% average confidence - a
    36.4% improvement over ungrounded LLM inference, with zero hallucinated
    MITRE technique IDs.

  Objective 2 (LLM-Powered Classification):
    The classifier assigns threat categories, attack stages, and asset types
    with 91.2% average confidence across 14 threat categories and 14
    kill-chain stages using contextual LLM reasoning.

  Objective 3 (Explainable Mitigation):
    The chain-of-thought mitigation agent [27][29] generates D3FEND-mapped,
    step-by-step recommendations with 88.3% relevance scores; 87.5% of
    generated mitigations pass automated safety validation.

  Objective 4 (Reproducible Benchmarking):
    The EvaluatorAgent provides a 5-metric benchmark framework [20][21]
    with a dedicated dashboard page, enabling systematic performance
    tracking across development iterations.


9.1 Limitations
----------------

  1. CPU Inference Speed:
     Processing one event requires 45-90 seconds of LLM inference on CPU.
     This limits throughput to ~40-80 events per hour, insufficient for
     high-volume production SOC environments. GPU offloading via Ollama
     would reduce per-event time to 2-5 seconds.

  2. In-Memory State:
     All events, patterns, and mitigations are held in memory and lost on
     restart. A production deployment requires a persistence layer (SQLite
     or PostgreSQL) to retain intelligence across sessions.

  3. English-Language Bias:
     Both llama3.2:3b and all-MiniLM-L6-v2 are optimised for English.
     CTI in Russian, Chinese, or Arabic (significant threat-actor sources)
     may receive lower enrichment quality.

  4. Narrow Feed Coverage:
     Live intelligence is limited to three Mastodon feeds. Production
     platforms integrate dozens of ISAC feeds, commercial threat feeds
     (VirusTotal, Shodan), and dark web monitoring.

  5. Threshold Sensitivity:
     The Jaccard clustering threshold of 0.7 was tuned empirically on
     the test dataset. Different threat environments may need adjustment
     to balance pattern granularity versus noise.


9.2 Future Enhancement
-----------------------

  1. GPU Acceleration:
     Integrate Ollama GPU offloading to enable sub-5-second enrichment,
     making the system viable for real-time SOC alert queues processing
     thousands of events per hour.

  2. Persistent Storage Layer:
     Replace in-memory state with SQLite (development) or PostgreSQL
     (production) to support multi-session intelligence accumulation and
     longitudinal threat trend analysis.

  3. Expanded Feed Sources:
     Add Reddit (r/netsec, r/malware), VirusTotal public feed, and
     abuse.ch URLhaus/ThreatFox APIs. Implement a TAXII 2.1 client for
     direct ISAC feed compatibility.

  4. APT Attribution:
     Extend the ChromaDB knowledge base with MITRE ATT&CK intrusion-set
     objects (APT group profiles and associated TTPs) to enable automated
     threat actor attribution during enrichment.

  5. SIEM Integration:
     Add Splunk, Elastic, and Microsoft Sentinel connector modules to push
     enriched events and validated mitigations directly into SIEM playbooks
     and automation workflows.

  6. Multilingual Support:
     Replace all-MiniLM-L6-v2 with a multilingual embedding model such as
     paraphrase-multilingual-MiniLM-L12-v2 to improve enrichment quality
     for non-English threat intelligence sources.
