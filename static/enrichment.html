2 Enrichment Agent

The second step. The Enrichment Agent sends each raw event to the local LLM and extracts structured threat intelligence from the unstructured text.
What happens here: Each raw event from the Ingestion Agent is sent to the local llama3.2:3b LLM running on Ollama. The AI reads the event text and extracts:

• IOCs (Indicators of Compromise) — IP addresses, domains, hashes, URLs
• TTPs (Tactics, Techniques, Procedures) — MITRE ATT&CK framework identifiers like T1059
• CVEs — Known vulnerability identifiers
• Affected Assets — Which systems or platforms are targeted
• Attack Vector — How the attack is being carried out
• Malware Family — If a known malware type is detected

In plain terms: This is like having a cybersecurity analyst read every alert and highlight the important details — which IPs are malicious, what attack techniques are being used, and what systems are at risk. The AI does this automatically in 20-60 seconds per event.
