1 Ingestion Agent

The first step in the pipeline. The Ingestion Agent collects raw security events from data sources (CSV, JSON files) and normalizes them into a standard format.
What happens here: The Ingestion Agent monitors the data/input/ directory for threat data files. When it finds CSV or JSON files, it reads each record, extracts key fields (IP addresses, descriptions, severity levels, timestamps), normalizes them into a consistent ThreatEvent format, and passes them to the next step — the Enrichment Agent.

In plain terms: Think of this as the "mailroom" of a Security Operations Center — it receives all incoming threat reports from various sources and organizes them into a standard format that the rest of the team can work with.
