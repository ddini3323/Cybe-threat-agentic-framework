3 Pattern Discovery Agent

The third step. The Pattern Discovery Agent groups enriched events that share common TTPs, malware families, or attack vectors into threat patterns.
What happens here: After the Enrichment Agent extracts TTPs (attack techniques) from each event, the Pattern Discovery Agent analyzes all enriched events together looking for commonalities. If multiple events share the same TTP (e.g., T1059 — Command and Scripting Interpreter), they are grouped into a threat pattern.

Why it matters: Individual alerts are noise. Patterns reveal coordinated attacks. If 3 different events all involve the same technique, it could indicate a single threat actor running a campaign — and that needs a unified response, not 3 separate ones.

In plain terms: This is like a detective connecting the dots between seemingly unrelated crimes — realizing they all use the same method (MO), happen in the same area, or target the same type of victim. The pattern tells you it's not random — it's organized.
