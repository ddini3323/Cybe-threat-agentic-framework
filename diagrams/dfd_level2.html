DFD Level 2 — Expanded Agent Sub-Processes
Chapter 4 · Section 4.4.3  |  Context-Aware Cyber Threat Analytics & Mitigation Recommendation
Figure 4.4a DFD Level 2 — Enrichment Agent (Expansion of P2)
Figure 4.4a — DFD Level 2: Enrichment Agent (P2 Expansion). This diagram expands Process P2 into seven sub-processes. Steps P2.2 and P2.3 perform semantic RAG retrieval from two ChromaDB collections (MITRE ATT&CK techniques and past threat reports). Step P2.4 assembles a structured four-section LLM prompt. Step P2.5 calls the local Ollama API (llama3.2:3b). Step P2.6 applies a three-stage JSON extraction pipeline followed by Pydantic validation. Step P2.7 stores the enriched event back into ChromaDB, completing the self-learning loop.
Figure 4.4b DFD Level 2 — Mitigation Agent (Expansion of P4)
Figure 4.4b — DFD Level 2: Mitigation Agent (P4 Expansion). This diagram expands Process P4 into five sub-processes. The agent accepts two types of input: newly discovered ThreatPattern objects (from Agent 3) and high-severity EnrichedEvents (severity ≥ 3). Step P4.1 determines which trigger applies. Step P4.2 constructs a three-part chain-of-thought prompt. Step P4.3 calls the same local Ollama instance used by the enrichment agent. Step P4.4 parses the response into a validated MitigationAction schema. Step P4.5 sets the status to PENDING_REVIEW, enforcing the human-in-the-loop approval gate.
